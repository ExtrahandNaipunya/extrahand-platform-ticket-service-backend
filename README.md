# ExtraHand Support Agent Backend Server

This is the backend component of the ExtraHand Support Agent Platform. It handles WebSocket connections for live chat and provides the REST API for session management.

**Note: For comprehensive documentation covering both Frontend and Backend, please refer to the unified README at the root:**
[README_SUPPORT_AGENT_PLATFORM.md](../README_SUPPORT_AGENT_PLATFORM.md)

## Quick Start
1. `npm install`
2. `npm run dev` (Runs on port 8001)
